Smart Water Distribution Scheduler — RTL → GDSII

One-hot valve arbitration · emergency pre-emption · skip-to-fit policy · SAED32 floorplan-to-GDSII on Synopsys DC + ICC2

Four city zones share one supply line: every clock, the chip decides who gets water. A two-pass combinational arbiter opens exactly one valve (one-hot, conflict-free in every run), lets priority-3 Emergency zones jump the queue, and — our innovation — skips-to-fit: when the winning request exceeds available supply the controller serves a smaller zone that does fit instead of stalling the city, while a live insufficient flag tracks the blocked zone. The frozen 223-line RTL passed 13/13 self-checking groups (35 checks) in an official VCS lab regression, then went through Design Compiler (+5.71 ns WNS at the ss/0.95 V/125 °C corner) and ICC2 floorplan → place → CTS → route to a signoff-clean 32 nm GDSII: +3.07 ns post-route slack, 0 hold violations, 0 DRCs, 0.03 ns skew.

  1. One-hot valve safety: the valve bus is decoded one-hot and re-checked by a continuous testbench monitor (onehot_bad) and independently in a simulator-free VCD audit — zero conflicts across all 83 main + 5 strict-policy valve transitions. A started serve always finishes: no mid-flush abort.
  2. Priority + emergency pre-emption: among zones that fit the current supply, highest zone_prio wins and ties break to the lowest index; priority-3 Emergency requests jump the queue at the next arbitration.
  3. Skip-to-fit — the team's innovation: if the highest-priority request does not fit supply_avail, the controller does not stall the city: it serves a smaller zone that does fit while the live insufficient flag stays high for the blocked zone. No request is ever dropped — the stuck zone is served the moment supply allows.
  4. Configurable policy: STRICT_PRIO parameter — 0 = work-conserving skip-to-fit (shipped config), 1 = strict priority where a stuck high-priority zone blocks all lower zones. Both policies are simulation-proven (T6/T7 vs T13).

A unified composite Galois-field GF(((2²)²)²) S-Box/InvS-Box shares 100% of the core multiplicative inversion logic across forward and inverse transformations — zero parallel inverse lookup tables instantiated.
  2. Active fault-tamper detection & 1-cycle zeroization: real-time datapath parity and consistency checking across round transitions. On fault injection the core aborts within 1 clock cycle, asserts the unmaskable security_irq, and atomically zero-wipes all 1,408 round-key registers and datapath state — status 0x0000000C observed in the injected-fault test.
  3. AMBA AXI4-Lite bus migration: point-to-point UART replaced by a standard 32-bit AXI4-Lite slave with non-blocking handshakes (AWREADY, WREADY, BVALID, ARREADY, RVALID) — zero bus lockup. Memory map spans CTRL/STATUS, KEY0–3, DIN0–3 and DOUT0–3 at 0x00–0x34.

12. FPGA PROOF10 Cycles Measured
  1. Area-efficient engine: one encryption round is reused across 10 rounds, with an initial AddRoundKey and on-the-fly generation of all 11 round keys. This avoids the area cost of a fully unrolled pipeline — the busy window is exactly ten cycles.
  2. AES transformations: 16 parallel S-Box lookups implement SubBytes; ShiftRows is pure wiring (0 cells); MixColumns performs GF(2⁸) matrix multiplication with a shared xtime; AddRoundKey XORs the 128-bit state.
  3. SoC interface: a 33-byte UART frame at 115200 8N1 sends 0xAE + key(16B) + plaintext(16B); the SoC replies 0xAA + ciphertext(16B). The final (least-significant) ciphertext byte drives LD0–LD7, giving 0x97 for NIST TV1. A 0x55 command asserts the error flag only.
  4. Standards verification: four known-answer vectors pass with zero bit errors on Icarus Verilog 11.0 and 12.0 — NIST SP 800-38A ECB TV1, FIPS-197 Appendix B, an all-zero KAT and an all-ones KAT. TV1 is additionally verified end-to-end on FPGA hardware.
  5. Design-for-test: a custom OpenLane 2 step runs OpenROAD scan_replace on the synthesized netlist, mapping 745/745 flip-flops (731 sdfrtp_2 + 14 sdfsbp_2) with zero RTL changes. A March C⁻ controller BISTs the 256×8 SRAM and was proven by fault injection — an injected stuck-at-0 at address 42, bit 0 is caught and the failing address reported.
  1. Timing closure: the DFT build closes a 20 ns / 50 MHz target with +7.22 ns worst setup (tt +14.06 ns) and +0.107 ns worst hold, reporting zero setup and hold violations across all nine corners. The no-DFT baseline held tt +14.07 ns setup / +0.29 ns hold.
  2. Physical implementation: the DFT configuration lands at 326,366 µm² die / 307,825 µm² core and 51.9% utilization; the baseline reached 240,307 / 224,240 µm² at 67.6%. Scan replacement grows synthesized cell area 44% (116.8k → 168.0k µm²), so the floorplan target was compensated to keep the build routable.
  3. Routing & signoff: detailed routing converged 16,062 → 0 DRC in seven iterations at 560,956 µm total wirelength with 0.021% worst IR drop. Magic and KLayout report 0 DRC, Netgen LVS is an exact match, and antenna checking leaves one net plus one pin residual, disclosed.
  4. Post-layout power: OpenSTA on the routed DEF with extracted SPEF at 50 MHz, activity 0.10, duty 0.5 gives 6.08 mW tt / 4.94 mW ss / 7.00 mW ff — 0.122 mW/MHz and 1.22 nJ per block, split 39.2% sequential, 29.4% combinational, 31.4% clock. This is analysis, not a silicon measurement.
  5. Measured hardware result: on a Basys3 (Artix-7 XC7A35T, Vivado 2017.4) an in-design cycle counter latches 10 cycles = 200 ns at 50 MHz = 0.64 Gbps; the UART returns the exact NIST TV1 ciphertext and the LEDs show 0x97.
  6. Honest benchmark: 10 cycles/block against 1,136 cycles/block for measured mbedTLS AES-128 on Cortex-M4 (114×) and ~1,280 for the fastest published fixsliced implementation (128×). The earlier 250× figure assumed an app-note software time and has been retired.

// 8-Bit 2-Stage Pipelined ALU in SkyWater Sky130A PDK
module alu_pipeline (
  input  wire       clk, rst,
  input  wire [7:0] a, b,
  input  wire [2:0] opcode,
  output reg  [7:0] result,
  output reg        valid
);
  reg [7:0] a_reg, b_reg, alu_result;
  reg [2:0] opcode_reg;
  reg       valid_stage1;
  // Stage 1: Input Registration on posedge clk
  always @(posedge clk or posedge rst) begin
    if (rst) begin
      a_reg <= 8'b0; b_reg <= 8'b0; opcode_reg <= 3'b0; valid_stage1 <= 1'b0;
    end else begin
      a_reg <= a; b_reg <= b; opcode_reg <= opcode; valid_stage1 <= 1'b1;
    end
  end
  // Combinational ALU Execution
  always @(*) begin
    case (opcode_reg)
      3'b000: alu_result = a_reg + b_reg; // ADD
      3'b001: alu_result = a_reg - b_reg; // SUB
      3'b010: alu_result = a_reg & b_reg; // AND
      3'b011: alu_result = a_reg | b_reg; // OR
      3'b100: alu_result = a_reg ^ b_reg; // XOR
      3'b101: alu_result = ~a_reg;        // NOT
      3'b110: alu_result = a_reg << 1;    // SLL
      3'b111: alu_result = a_reg >> 1;    // SRL
      default: alu_result = 8'b0;
    endcase
  end
  // Stage 2: Output Registration
  always @(posedge clk or posedge rst) begin
    if (rst) begin
      result <= 8'b0; valid <= 1'b0;
    end else begin
      result <= alu_result; valid <= valid_stage1;
    end
  end
endmodule
